Basketball Shot-Make Probability

A basketball shot-probability modeling project focused on prediction quality, calibration, and validation across seasons.

The question

How accurately can shot characteristics predict make probability on unseen data?

What I built and explored

  • Built a logistic regression baseline with basketball-specific features.
  • Compared generalized additive models and XGBoost candidates.
  • Evaluated cross-season performance and checked calibration.
  • Prioritized leakage prevention and probability quality, not only classification accuracy.

Tools and methods

R, statistical modeling, cross-validation, calibration, XGBoost

Takeaway

Model evaluation and calibration matter when probabilities need to be meaningful on future data.

This case study is a high-level summary. Model outputs, restricted data, and code are not provided publicly here.
