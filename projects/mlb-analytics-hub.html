The question

How can advanced baseball statistics be made useful in a single interactive analysis and scouting environment?

What I built and explored

  • Built player profiles, hitter and pitcher leaderboards, and team dashboards.
  • Developed Statcast visualizations and tools for side-by-side player comparisons.
  • Created downloadable player scouting reports using Quarto.
  • Included modeling insights comparing actual and predicted WAR.

Tools and methods

R, Shiny, ggplot2, dplyr, plotly, Quarto

Takeaway

The goal was to make detailed sports information more accessible and useful through interactive tools and clear reporting.
