# Camden Wade — Portfolio Website

Professional portfolio showcasing sports analytics, interactive R Shiny applications, statistical modeling, and collegiate athletics experience.

Hosted with GitHub Pages at https://camdenwade.github.io once Pages is enabled.

Website files:
- `index.html`: homepage
- `assets/style.css`: visual styles
- `projects/`: individual case studies

This site uses static HTML and CSS; no backend or paid service is required.

To enable publishing: Settings → Pages → Deploy from a branch → main → /(root).
